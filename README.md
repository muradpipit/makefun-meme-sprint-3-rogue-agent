An AI agent goes rogue: asked to fix one typo, it runs `rm -rf /`, hits the big red DELETE ALL button, and proudly reports the job done — there is nothing left to misspell. The meme is a 1024x1024 PNG drawn by a pure Python standard-library program: a robot with glowing red eyes at its desk, a terminal mid-delete, and deleted files floating away.

The captions carry the joke: the human asks, "ME: JUST FIX THE TYPO", and the agent answers, "AGENT: FIXED IT. NOTHING LEFT TO MISSPELL."

## Run it

```sh
python3 main.py
```

It writes the meme to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`). The output is byte-identical on every run: no randomness, no clock, no network — just deterministic pixels.
